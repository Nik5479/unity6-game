# THE FORGOTTEN VILLAGE — Verified Model Download Links, ROUND 2 (2026-11-07)

**Purpose:** round 2 covers the 5 items round 1 could NOT find (House_2,
second hut, Clinic, Dog, Monster). The user is downloading right now — every
link below was researched and verified from the model page (or the Sketchfab
public API where a page fetch timed out) before he downloads anything.
**Nothing was downloaded by the assistant and no project file was changed.**

**How verification was done:** 5 researchers, one per item, with fresh
search terms and fresh sources (Sketchfab, Fab free section, CGTrader free,
TurboSquid free). Every candidate was opened on its own model page or checked
via the Sketchfab public API — never trusted from search snippets. A link is
listed as VERIFIED only when the page/API itself showed: downloadable
("Download Free" / `isDownloadable: true`), a game-use licence (CC-BY / CC0 /
Sketchfab Standard / Fab Standard), and a triangle count in (or near) the
target range and under the 500k hard cap. Rejected candidates are listed per
item so nobody re-suggests them.

**Verification limits (read this — honest gaps):**
- Sketchfab page text usually does **not** list PBR maps by name, file size,
  or the download-format picker. So "PBR confirmed" below means the page
  proves textures exist / lists maps where stated; otherwise it says
  "PBR unconfirmed — check after download". After downloading, open the
  `.glb` and check for normal/roughness maps before using it (the same check
  the asset audit used).
- On Sketchfab, always pick **glTF** (or GLB) in the download dialog — the
  format list is not visible on the crawled pages, so confirm it on the
  download screen.
- Some candidates below are API-verified only (page fetch timed out) — they
  are flagged as such. A tap on the link to confirm it opens is still needed
  before downloading.
- CC-BY models need the author credited (add to the project README).

**Score: 2 of 5 items have a verified primary link** (House_2, Clinic)
**+ 2 conditional/compromise primaries** (second hut, Monster — neither is a
clean match, see their caveats) **+ 1 item with NO good link** (Dog).
